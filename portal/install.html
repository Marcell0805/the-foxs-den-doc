Install help

One guide for everything published from the workshop. Pick the kind of download you have.

Android apps Windows tools Browser add-ons

Android apps

Download APKs only from this site, using the button on each app’s page. Android will ask extra questions because the app is not coming from the Play Store. That is normal for these builds.

Some apps, such as FFS, also have Get it on Google Play. Play Store copies update through Play. Sideloaded copies update from the APK link on the project page.

  1. Open the app’s page and tap Download.
  2. Open the file from Chrome, Files, or Google Drive.
  3. If asked, allow Install unknown apps for the app you used to open it.
  4. If Play Protect says the app is uncommon, choose Install anyway or More details, then continue.
  5. Open the app. The name and icon should match the listing in The Den.

Updating

If an older test build with the same package name is already installed, uninstall it first, then install the new release.

Some apps check for a newer build when they are online and show release notes with a download link. Content-only updates, such as cookbook recipes, can arrive separately from the app itself.

Windows tools

Desktop tools are a zip file. There is no installer.

  1. On the project page, download the zip.
  2. Extract it to a folder you can find again.
  3. Run the .exe inside that folder.
StreamForge does not include Discord secrets in the download. After it opens, sign in or add a bot token from Settings. Keep tokens on your PC only.

Browser add-ons

Use the Chrome Web Store button when the project page offers one. That is the simplest install and the one that receives store updates.

Install from the zip

  1. Download the zip from the project page and extract it.
  2. Open chrome://extensions.
  3. Turn on Developer mode.
  4. Choose Load unpacked and select the extracted folder.

If the zip includes an INSTALL-CHROME.md file, follow that for anything specific to the add-on.
